# 蜂王浆.cn · 蜂王浆行业黄页站

蜂王浆品牌与商家信息黄页，单文件静态站点（`index.html` + `assets/`），可直接部署到 GitHub Pages 或任意静态托管。

## 页面结构

- 首页：搜索、品牌速览、行业科普入口、入驻引导
- 品牌黄页：12 个蜂王浆品牌名录，支持关键词搜索与类型筛选
- 知识科普：蜂王浆介绍、营养成分、食用方法、保存与选购要点
- 商家入驻：免费收录，联系邮箱 mfujun@agent.qq.com

## 技术说明

- 单文件自包含 HTML，CSS/JS 内联，hash 路由切换视图
- 品牌资料整理自公开网络信息，页面已含免责声明
- 图片位于 `assets/`，发布时需连同目录一起部署

## 本地打开

直接双击 `index.html` 即可，或通过 GitHub Pages 访问在线版本。
